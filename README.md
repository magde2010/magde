# Lotfe — MEXC Spot Portfolio Bot

بوت إدارة محافظ MEXC Spot فقط.

## إدارة المحافظ
- إنشاء المحافظ وتشغيلها وإيقافها وإدارة المراكز.
- إعداد أهداف الربح ووقف الخسارة.
- عرض الرصيد وتنظيف بيانات المحافظ.
- حماية صلاحيات الإدارة: `ADMIN_TELEGRAM_ID` مطلوب ويجب أن يكون رقم Telegram موجبًا وصحيحًا.

## متطلبات التشغيل
`TELEGRAM_BOT_TOKEN`, `MEXC_API_KEY`, `MEXC_API_SECRET`, `DATABASE_URL`, `ADMIN_TELEGRAM_ID`

استخدم مفاتيح MEXC بصلاحيات Spot اللازمة فقط، وعطّل صلاحية السحب. اختبر التغييرات على حساب تجريبي أو بمبالغ صغيرة قبل التداول الحقيقي.
