# MEXC SPOT Auto Trader v2.1

## المتغيرات في Railway (4 فقط + اختياري)
```
TELEGRAM_BOT_TOKEN=
TELEGRAM_ADMIN_ID=
MEXC_API_KEY=
MEXC_SECRET_KEY=
# DATABASE_URL=   (لو أضفت Postgres)
```

يقبل البوت أيضًا الاسمين القديمين `ADMIN_TELEGRAM_ID` و`MEXC_API_SECRET` للتوافق.
إذا ظهر خطأ عن المتغيرات الناقصة، أضف `TELEGRAM_BOT_TOKEN` و`TELEGRAM_ADMIN_ID`
من إعدادات Variables في Railway ثم أعد النشر.

## الجديد في هذه النسخة
- منع تكرار شراء نفس العملة لو الصفقة لسه مفتوحة
- منع تكرار نفس الرسالة (Message ID + Hash)
- دعم نموذجين للإشارات (عربي سبوت + إنجليزي Long)
- زر **نموذج** لكل قناة لاختيار شكل التوصية
- قراءة الأهداف المتعددة من التوصية نفسها (هدف 1/2/3)
- استخدام وقف التوصية كوقف أولي

## التحكم كله من الأزرار
مبلغ الصفقة، Paper، تشغيل/إيقاف، حد الصفقات، نسب TP، إدارة القنوات والنماذج.


## إصلاحات وملاحظات تشغيل

- وضع Paper يستخدم أسعار السوق العامة لمحاكاة TP/SL، حتى لو لم تكن مفاتيح MEXC موجودة. لا تُنشأ صفقة Paper إذا لم يتوفر سعر صالح.
- إدارة كل مركز تعتمد على وضعه المحفوظ عند فتحه، وليس على زر Paper الحالي، حتى لا تتوقف إدارة مركز حقيقي عند تغيير الإعداد العام.
- يمنع المحلل اعتبار كلمات مثل BUY وENTRY أو أرقام الأسعار رموز عملات، ويعطي أولوية لإشارة SHORT الصريحة على كلمة SPOT.
- تحديث مؤشر رسائل القنوات بعد معالجة المنشورات يمنع إعادة فحص نفس المنشورات غير المتعلقة بالتداول باستمرار.
- يسجل سجل الصفقات عمليات البيع الجزئي TP1 وTP2، ويستخدم سعر التنفيذ المتاح من رد البورصة عند تسجيل الخروج.
- التداول الحقيقي يتطلب مفتاحي MEXC. ابدأ بوضع Paper واختبر السلوك قبل تفعيل الأوامر الحقيقية.

## الاختبارات

بعد تثبيت `requirements.txt`، شغّل:

```bash
python -m unittest discover -s tests -v
```

الاختبارات تستخدم بورصة وهمية ولا ترسل أوامر تداول حقيقية.
