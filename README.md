# Lotfe — MEXC Spot Bot

بوت إدارة محافظ MEXC بنظام يدوي فقط، مع إدارة الرصيد والإعدادات وتنظيف بيانات المحافظ.

## إدارة المحافظ

- TP1 وTP2 ونسب البيع ووقف الخسارة يحددها المستخدم.
- لا يوجد أي وضع تداول آلي أو شراء تلقائي؛ كل الأوامر ينفذها المستخدم.
- بعد TP1 وTP2 يبقى الجزء المتبقي تحت قواعد الاستوب اليدوي وإعادة الدخول المحددة.
- إعادة بناء المراكز تطبق إعدادات المحفظة اليدوية وتحافظ على سجلات المحافظ والصفقات.

## البيانات

تم الحفاظ على قاعدة البيانات والجداول والسجلات الحالية. تم توحيد `control_mode` للمحافظ إلى `manual` دون حذف المحافظ أو الصفقات أو سجل الأحداث.

## البيئة

`TELEGRAM_BOT_TOKEN`, `MEXC_API_KEY`, `MEXC_API_SECRET`, `DATABASE_URL`, `ADMIN_TELEGRAM_ID`
