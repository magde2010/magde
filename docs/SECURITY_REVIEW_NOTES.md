# ملاحظات الإصلاح الأمني والتشغيلي

هذه النسخة تحافظ على نظام المحافظ فقط، ولا تحتوي على نظام Grid.

## التغييرات الأساسية
- منع بيع رصيد العملة إذا كانت الكمية مخصصة أيضًا لمركز في محفظة أخرى على حساب MEXC نفسه.
- رفض البيع عند وجود أوامر بيع مفتوحة غير محسومة، وعدم إلغاء أوامر لا يملكها المركز.
- التحقق من الحالة النهائية للأمر والكمية المنفذة الفعلية قبل تحديث سجل المركز أو حذفه.
- تسوية تعبئات أوامر TP المؤكدة بعد الإلغاء قبل بيع المتبقي عند حذف عملة.
- عدم افتراض كمية تنفيذ لأهداف TP عند غياب بيانات التعبئة، وعدم اعتبار الغبار غير الصفري إغلاقًا كاملًا.
- عدم تصنيف أخطاء منصة عامة مثل `filter failure` على أنها غبار، وتمرير أخطاء نتيجة الإرسال غير المحسومة للمراجعة.
- استخدام مسار الإيقاف الآمن عند إغلاق المحفظة، وعدم إغلاقها إذا بقيت مراكز غير محسومة.
- منع بدء/إعادة بناء/إعادة دخول محفظة على عملة مخصصة بالفعل لمحفظة أخرى.

## الاختبارات
تم تشغيل `python -m compileall -q .` و`pytest -q` محليًا. الاختبارات تغطي حالات منطقية باستخدام بيانات وهمية؛ لم تُرسل أوامر حقيقية إلى MEXC ولم يُجرَ اختبار حي على Telegram/Railway.
