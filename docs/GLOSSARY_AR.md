## 2) جدول المصطلحات المبسّطة (انسخه كما هو داخل البوت)

| المصطلح في البوت | الشرح المبسّط الذي يظهر للمستخدم |
|---|---|
| DCA / الشراء على دفعات | مش هتشتري كل المبلغ مرة واحدة، هتشتري على دفعات. لو السعر نزل تشتري كمية إضافية فيقل متوسط سعر الشراء. |
| احتياطي DCA | جزء من الفلوس بتحتفظ به جانبًا ومش بيدخل الشراء الأول، مخصص للدفعات الإضافية. |
| الأمر المحدد (Limit) | طلب شراء بسعر انت تحدده؛ اتنفّذ فقط لو السعر وصل له أو نزل تحته. |
| المبلغ المخصص | المبلغ اللي محدد للمحفظة ككل؛ منه بيتوزّع الشراء الأول والاحتياطي. |
| إعادة التوازن | إعادة توزيع المبلغ على العملات بالنسب اللي انت محددها. |
| تخفيف الحيازة | تبيع جزء من كمية العملة (25%/50%/70%) وباقي الكمية تفضل معاك. |
| استرجاع الكميات المخفَّفة | ترجّع الكمية اللي باعها التخفيف بمبلغ من المخصص. |
| وقف الخسارة | سعر تحدده انت؛ لو السعر نزل له البوت يبيع تلقائيًا. |
| هدف الربح | سعر تحدده انت؛ لو السعر وصل له البوت يبيع ويحقق الربح. |
| المراقبة السحابية | البوت شغّال على السيرفر بيفحص الأسعار كل ثواني ويبيع تلقائيًا. |
| الرصيد المتاح / الحر | الفلوس اللي مش محجوزة في أي طلب؛ تقدر تشغلها أو تسحبها فورًا. |
| المحفظة | خطة استثمار واحدة: عملات + مبلغ + أهداف ووقف خسارة. |
| الحد الأدنى للأمر | أقل مبلغ MEXC بيقبل الطلب بيه (2 USDT تقريبًا في المشروع). |
| الرسوم | عمولة MEXC على كل شراء أو بيع — بتتخصم من المبلغ. |
| الانزلاق السعري | الفرق بين السعر اللي شفته والسعر الفعلي للتنفيذ. |
| الوضع التجريبي | تشغيل الخطة للتجربة بدون أوامر بفلوس حقيقية. |
| USDT | عملة رقمية ثابتة ≈ 1 دولار، بنقيس بيها قيمة المحفظة. |

## 3) قواعد الشكل الاحترافي (مُطبَّقة في ui_theme.py 4.0)

1. **خط عريض بعين واضحة:** العريض للحقول المهمة والقيم فقط، لا لكل السطر.
   العريض في تيليجرام = `*نص*` (لا تستخدم `**` مع `parse_mode="Markdown"`).
2. **لا إطار مغلق على اليمين:** كل `┃` أو `┓` في نهاية السطر تنكسر مع النص العربي
   لأن عرض الحروف يتفاوت → استبدلها بفاصل أفقي `━━━━` بعد العنوان.
3. **انسيابية (Flow):** سطر واحد فارغ بين البلوكات، وفاصل خفيف `────` قبل التذييل.
4. **سطر لكل معلومة:** `• التسمية: **القيمة**` بدل الفواصل المتلاصقة.
5. **الأرقام بفواصل آلاف:** `12,450.75` أسرع في القراءة من `12450.75`.
6. **شريط تقدّم بصري:** `▰▰▰▰▱▱▱▱▱▱ 40%` بدل "نسبة الإنجاز 40%".
7. **حالة واضحة:** 🟢 يعمل / ⚪ متوقف في أول سطر من بطاقة المحفظة.
8. **نصوص الأزرار لا تقبل عريضًا** في تيليجرام — الأزرار تبقى أيقونة + كلمة قصيرة،
   والعريض يكون في نص الرسالة فقط.
9. **تهريب النصوص الديناميكية:** أي اسم محفظة أو سبب خطأ يمرّ على `ui.safe()`
   لمنع خطأ `Can't parse entities`.
10. **رابط المساعدة داخل كل شاشة معقدة:** أضف `ui.HELP_HINT` في نهاية الرسائل،
    وزر `❓ شرح` بـ `callback_data="help"` لعرض صفحة القاموس.

# شاشة المحفظة بشكل احترافي
text = (

await update.message.reply_text(text, parse_mode="Markdown", reply_markup=kb)

## 6) خريطة تحسين النصوص الحالية في bot.py

| مكان في bot.py | التغيير المقترح |
|---|---|
| `start_cmd` (سطر ~1620) | أبقِ `ui.page_title` ثم أضف `+"\n"+ui.tip("اختر من الأزرار بالأسفل")`. |
| `cancel_cmd` (سطر ~1635) | استخدم `ui.page(ui.I["home"], "لوحة التحكم", "اختر القسم المطلوب:")`. |
| شاشات الأخطاء (`⚠`) | اجعل السطر الأول عريضًا فقط: `ui.title(ui.I["warning"], "تحقق من المدخل")` ثم التفاصيل عادية. |
| رسائل DCA الثلاث | أضف بعد كل سؤال سطر `ui.explain("dca")` مرة واحدة فقط لتقليل الإزعاج. |
| شاشة الرصيد (سطر ~1822) | استبدل `الإجمالي ≈ \`x\`` بـ `ui.kv("إجمالي الرصيد", f"{ui.money(total)} USDT")`. |
